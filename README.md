# Yuhao Pan — research homepage

Personal academic website: https://yyyyu120.github.io/

Based on [w-r-s/academic-homepage-template](https://github.com/w-r-s/academic-homepage-template). A static HTML, CSS, and JavaScript website with no build step.

## Local preview

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765/ in a browser.

## Deployment

GitHub Pages serves the root of the `main` branch. Update `index.html` for content and `custom.css` for styling, then push to `main`.
